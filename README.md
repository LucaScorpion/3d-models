# 3D Models

This repository contains my 3D printing model collection.
All models are made using [OpenSCAD](https://openscad.org), and I aim to make everything as customizable as possible.

You can find more information for each model on [my website](https://www.scalzotto.nl/posts/categories/3d-printing),
and you can find me on [Printables](https://www.printables.com/@LucaScorpion_5215438).

## Models

### Medicine box rack

A holder for pillboxes/medicine boxes/blister packs, to keep your bathroom cabinets neatly organised.

![](./Medicine%20box%20rack/Medicine%20box%20rack.png)

### Pencil holder

A holder for eye pencils, perfume testers, or any set of cylindrical items.

![](./Pencil%20holder/Pencil%20holder.png)

### Skadis universal container

A universal container designed to fit the IKEA SKADIS pegboard system,
based on the universal hook from [CSD_Salzburg](https://www.thingiverse.com/thing:2853261).

![](./Skadis/Universal%20container.png)

### Spool holder

A custom spool holder for your 3D printer, designed for ball bearings.

![](./Spool%20holder/Spool%20holder.png)

### Tablet wall mount

A universal tablet wall mount, with a slot for an angled magnetic charger.

![](./Tablet%20wall%20mount/Tablet%20wall%20mount.png)
